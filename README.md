# esmeda-releases

Official release artifacts, digital signatures, and updater manifests for the **Esmeda** desktop application.

## Overview
- **Application:** Esmeda (Local-first personal administration & finance for Switzerland)
- **Publisher:** [mesutkarabulut](https://github.com/mesutkarabulut)
- **Supported Architecture:** Windows x64 (`.exe`, `.msi`)
- **Verification:** Cryptographically signed with Minisign (Ed25519)

## Automatic Updates
Updates are securely delivered to the desktop application via the Tauri v2 updater engine using `latest.json`.
